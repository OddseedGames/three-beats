# Три такта · OddseedGames

[![CI and Pages](https://github.com/OddseedGames/three-beats/actions/workflows/ci.yml/badge.svg)](https://github.com/OddseedGames/three-beats/actions/workflows/ci.yml)

**[Играть](https://oddseedgames.github.io/three-beats/)** · **[Скачать ZIP](https://oddseedgames.github.io/three-beats/OddseedGames-ThreeBeats.zip)**

Пошаговый файтинг на Rust + Macroquad. Противник открывает свою комбинацию, ты составляешь ответ на три такта. Обе серии исполняются одновременно. Дистанция, выносливость и момент удара определяют результат; случайных промахов нет.

Третья самостоятельная учебная игра OddseedGames. Вид сбоку, семь позиций на ринге, восемь действий и турнир против трёх бойцов: Рывок давит джебами, Контра защищается и держит дистанцию, Гром использует тяжёлые удары. После победы перед следующим боем здоровье и энергия восстанавливаются.

## Запуск и управление

Открой `dist/play.html` двойным щелчком либо распакуй ZIP и открой `play.html` внутри. Сервер, интернет и установка Rust для игры не нужны. Нужен браузер с WebGL/WebAssembly. Игра проверяется в настольном Chrome/Chromium. Звук изначально выключен.

| Ввод | Действие |
| --- | --- |
| Enter | Начать / исполнить полную серию / следующий бой |
| 1 / 2 / 3 | Джеб / тяжёлый удар / удар ногой |
| 4 / 5 | Шаг вперёд / назад |
| 6 / 7 / 8 | Блок / уклон / передышка |
| Backspace / C | Удалить последний приём / очистить серию |
| H | Правила |
| P / Escape | Пауза / продолжить |
| R | Новый турнир |
| M | Звук |

Все приёмы и кнопки доступны мышью. Время планирования не ограничено. При потере фокуса исполнение серии ставится на паузу.

## Правила

| Приём | Такты | Энергия | Результат |
| --- | ---: | ---: | --- |
| Джеб | 1 | 2 | 3 урона, дистанция 1 |
| Тяжёлый удар | 2 | 4 | Замах, затем 7 урона на дистанции 1; отбрасывает |
| Удар ногой | 2 | 3 | Замах, затем 4 урона на дистанции 1-2; отбрасывает |
| Шаг вперёд / назад | 1 | 1 | Переместиться на одну позицию |
| Блок | 1 | 1 | Пропустить треть урона с округлением вверх, предотвратить отбрасывание |
| Уклон | 1 | 3 | Избежать всех ударов в этот такт без смены позиции |
| Передышка | 1 | 0 | Восстановить 3 энергии, максимум 8 |

За серию нужно занять ровно три такта; приём на два такта нельзя начать в последней ячейке. Планировщик учитывает расходы и передышки в порядке действий и не позволяет составить неоплачиваемую серию. Между сериями оба бойца восстанавливают ещё 1 энергию.

Движение разрешается первым. Если бойцы пытаются занять одну клетку или пройти друг сквозь друга, оба перемещения отменяются. Затем рассчитываются удары на новой дистанции. Оба попадания в одном такте применяются одновременно: возможен обоюдный нокаут, который завершает турнир поражением игрока.

Попадание во время замаха срывает следующую фазу удара. Потраченная энергия не возвращается, сорванная фаза не даёт бесплатной защиты. Блок и уклон действуют только в своей ячейке времени. При нокауте оставшиеся такты отменяются. У Новы 24 здоровья, у соперников 16 / 20 / 26. Намерение ИИ фиксируется до выбора игрока.

## Разработка

Нужны rustup и Python 3. `rust-toolchain.toml` закрепляет Rust 1.99.1, rustfmt и `wasm32-unknown-unknown`. Скрипты используют Rust из соседней `../.tools`, если он установлен, иначе из PATH. После клонирования выполни `cargo fetch --locked`; затем проверки и сборка могут работать без сети.

```sh
./scripts/check.sh
./scripts/build.sh
./scripts/dev.sh
```

Сервер разработки: `http://127.0.0.1:8029`. Нативный запуск: `./scripts/run-native.sh`. На Linux для нативной сборки нужны `pkg-config libx11-dev libxi-dev libgl1-mesa-dev libasound2-dev`; на Windows shell-скрипты запускаются через Git Bash, Rust-проверки — напрямую через Cargo.

Сборка создаёт сайт `dist/index.html`, автономный `dist/play.html`, ZIP и `build.json` с SHA коммита и контрольными суммами файлов. WASM в сетевом загрузчике получает версию по хешу. Упаковка проверяет встроенный WASM и содержимое ZIP.

## Модули

| Модуль | Ответственность |
| --- | --- |
| `src/main.rs`, `src/app.rs` | Вход, цикл приложения и переходы интерфейса |
| `src/combat/action.rs` | Каталог приёмов, стоимость и длительность |
| `src/combat/state.rs` | Бойцы и результат одного такта |
| `src/combat/resolve.rs` | Чистое разрешение движения, ударов, защиты и прерываний |
| `src/plan.rs` | Очередь действий, бюджет времени и энергии |
| `src/ai.rs` | Предсказуемые стили соперников |
| `src/game.rs` | Серии, проигрывание, победы и турнир |
| `src/input.rs`, `src/layout.rs` | Ввод и общая геометрия кнопок |
| `src/view/` | Ринг, персонажи, индикаторы, планировщик и меню |
| `src/audio.rs`, `src/browser.rs` | Звук и браузерный жизненный цикл |

Боевые правила, ИИ и планировщик не зависят от графического контекста. Тесты проверяют порядок разрешения, расходы энергии, границы ринга, прерывания, одновременный нокаут и достижимость победы во всём турнире.

Браузерные проверки:

```sh
python3 -m pip install -r tests/browser/requirements.txt
python3 -m playwright install chromium
python3 -m unittest discover -s tests/browser -v
```

CI проверяет Rust на Linux и Windows, собирает WASM, проверяет автономный HTML в Chromium без сети и только затем публикует `main` на GitHub Pages. Для pull request публикация не выполняется. При сбое сохраняются скриншоты и трассировки; HTML и ZIP доступны в артефактах успешной сборки.

## Материалы

Учебный прототип создан с помощью ИИ: код, программная графика и синтез звуков. Ассетов из других игр нет. Игровые правила и отрисовка выполняются в Rust/WASM; JavaScript загружает движок, обеспечивает браузерный ввод, полноэкранный режим и диагностику.
